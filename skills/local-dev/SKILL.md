# Local Development & Deployment

## How qmd is installed

qmd is NOT installed via `bun link` or npm. It's a Nix flake consumed
as an input to Sebastian's nix-config:

1. This repo (`github:sh54/qmd`) is a flake input in `~/nix-config`
2. The flake builds qmd via `stdenv.mkDerivation` with bun2nix
3. `bb switch` (nix-darwin/NixOS rebuild) deploys it system-wide
4. The installed binary is a bash wrapper at
   `/etc/profiles/per-user/sh54/bin/qmd` that runs bun with the
   correct library paths (SQLite, libstdc++, glibc)

**The installed qmd always points to a Nix store path** — it does NOT
read from this working directory. Local source changes require either
a rebuild (`bb switch`) or running from source directly.

## Running from source

Enter the devshell first — never use system `bun`:

```bash
ndev bun src/qmd.ts <command>
# or
nix develop -c bun src/qmd.ts <command>
```

The devshell provides bun, bun2nix, and sqlite with extension loading.

After rebasing or pulling upstream, install deps first:

```bash
ndev bun install
```

## Testing changes before deploy

```bash
# Run from source to verify
ndev bun src/qmd.ts search "test query" -c roam -n 3

# Run tests
ndev bun test --preload ./src/test-preload.ts test/

# When satisfied, push and rebuild nix-config
# (in ~/nix-config: update the qmd input, then bb switch)
```

## Updating the Nix build after dependency changes

If upstream changed `package.json` / `bun.lock`, regenerate `bun.nix`:

```bash
ndev bun2nix
git add bun.nix bun.lock
```

## Known issue: bun2nix EACCES hang

After a rebase that changes dependencies, `nix build` may hang during
`bunNodeModulesInstallPhase` with errors like:

```
error: moving "@node-llama-cpp/mac-arm64-metal" to cache dir failed:
  EACCES: Permission denied (rename())
```

**Root cause:** bun2nix copies `bunDeps` from the read-only Nix store
into a writable tmpdir via `cp -r`, but `cp -r` preserves store
permissions (read-only). Bun's `rename()` into the cache then fails
and hangs instead of erroring out (known bun bug).

**Fix in `flake.nix`:**

```nix
postBunSetInstallCacheDirPhase = ''
  chmod -R u+w "$BUN_INSTALL_CACHE_DIR"
'';
```

**After ANY rebase that changes upstream deps**, always regenerate
`bun.nix`:

```bash
ndev bun2nix
git add bun.nix bun.lock
```

## Debugging builds

Use `-L` to see full build logs instead of the progress bar:

```bash
nix build .# -L
```

## Key files

- `flake.nix` — Nix package definition, devshell, bun2nix integration
- `bun.nix` — Generated by bun2nix, lock file for Nix builds
- `bunfig.toml` — Bun configuration
- `src/qmd.ts` — Main CLI entry point
- `src/store.ts` — SQLite store (contains `encodeQmdPath`)
